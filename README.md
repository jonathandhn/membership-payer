# Membership Payer

A CiviCRM extension that separates the organisation paying for an online
membership from the individual member.

- **Organisation**: Payer, invoice & receipt contact.
- **Individual**: Membership owner & rights holder.

## Configuration

1. Go to **Administer > CiviContribute Settings > Pages de contribution avec
   adhésion réglée par une entreprise**
   (`civicrm/admin/setting/membership-payer`).
2. Select the legacy contribution pages where organisations pay for individual
   memberships.

> **Requirement**: Contribution pages must have *Contribution on behalf of an
> organisation* enabled with an organisation profile.
